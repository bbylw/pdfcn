## 特性

- ⚡ **双渲染引擎** — 使用 Takumi 或 Forme 生成 PDF
- 🎯 **零配置** — 开箱即用，内置合理的默认配置
- 👀 **实时预览** — 在文档中直接渲染每个组件与区块
- 🎨 **完全可定制** — 提供合理的属性与共享主题；代码归你所有
- 📦 **兼容 shadcn/ui** — 使用相同的注册表格式与 CLI 工作流
- 🧩 **可组合** — 用聚焦的 React 组件与渲染原语构建文档
- 📄 **组件与区块** — 表格、表单、图表、发票、报告等
