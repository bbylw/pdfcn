我们发布了主题构建器（Theme Builder），这是一个用于自定义 PDF 主题的可视化编辑器，提供实时预览、即时反馈和一键代码导出。

### 新增内容

- **实时 PDF 预览**：调整颜色、排版、间距和页面设置时，实时查看主题的应用效果
- **主题选择器**：浏览并切换 9 个内置的[预设](/docs/themes)（Professional、Modern、Minimal、Executive、Corporate、Elegant、Vivid、Forest、Blueprint）
- **撤销 / 重做**：完整的历史记录，支持键盘快捷键（⌘Z / ⌘⇧Z）
- **代码导出**：将主题配置复制为 JSON 对象或 TypeScript 预设，直接放入你的项目中
- **可分享的 URL**：主题状态编码在 URL 哈希中，方便你与任何人分享精确的配置
- **按基础库路由**：为 [Takumi PDF](https://pdfcn.dev/theme-builder/takumi) 和 [Forme PDF](https://pdfcn.dev/theme-builder/forme) 提供独立的主题构建器
- **字体预览**：在生成 PDF 之前，以实际大小预览所选正文字体和标题字体的效果
